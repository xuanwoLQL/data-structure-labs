# 数据结构课程实验合集（C++）

数据结构课程的 10 个实验 + 1 个课程设计，全部用 C++ 手写实现，**不依赖任何第三方库**。

每个实验都是独立可编译的多文件工程（`.h` 声明 + `.cpp` 实现 + `main.cpp` 菜单驱动）。

## 实验清单

| 目录 | 实验内容 | 核心数据结构 |
| --- | --- | --- |
| `01-linear-list/` | 线性表的应用：顺序表 / 单链表、有序表合并、稀疏多项式加减 | 顺序表、单链表 |
| `02-stack-queue/` | 栈和队列：数制转换、表达式求值、舞伴配对（含文件读入） | 顺序栈、链栈、循环队列 |
| `03-binary-tree/` | 二叉树的建立与遍历：前/中/后序（递归 + 非递归）、深度、叶子数 | 二叉树、链队列、链栈 |
| `04-huffman-tree/` | 哈夫曼树及哈夫曼编码：建树、求编码、计算带权路径长度 | 哈夫曼树 |
| `05-graph-traversal/` | 图的遍历：邻接矩阵 / 邻接表的 DFS 与 BFS | 邻接矩阵、邻接表 |
| `06-mst-topological/` | 最小生成树（Prim）与拓扑排序 | 邻接矩阵、邻接表 |
| `07-critical-path/` | 关键路径与最短路径 | 邻接表、AOE 网 |
| `08-search-sort/` | 查找与排序 | 折半查找、多种排序 |
| `09-graph-definition/` | 图的综合应用：存储结构、遍历、最小生成树、最短路径、AOE 关键路径 | 邻接矩阵、邻接表 |
| `10-huffman-codec/` | **课程设计**：哈夫曼编/译码器系统（读文件 → 统计频率 → 建树 → 生成编码 → 编码/译码 → 性能报告 → 打印树形） | 哈夫曼树、编码表 |
| `extra/` | 线性表 / 顺序表 / 复数的其他实现版本 | — |

## 编译运行

每个目录单独编译，把该目录下所有 `.cpp` 一起交给编译器即可：

```bash
cd 03-binary-tree
g++ -std=c++14 -o binary_tree *.cpp
./binary_tree
```

Windows 下 `g++.exe` 生成的同样可用。程序都是菜单驱动的交互式界面，按提示输入数字选择功能，输入 `0` 退出。

`10-huffman-codec` 需要先准备一个待编码的文本文件（仓库里带了 `TextFile.txt` 等样例数据），启动后选 `1.读取文本文件` 输入文件名即可。
